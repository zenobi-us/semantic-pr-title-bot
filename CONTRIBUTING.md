## Contributing

## Issues and PRs

Found a bug or have a feature suggestion? Open an issue. Interested in contributing code? Submit a PR.

For large changes, open an issue first to discuss.

## Submitting a pull request

1. Fork and clone the repository.
1. Configure and install the dependencies: `npm install`.
1. Make sure the tests pass on your machine: `npm test`, note: these tests also apply the linter, so there's no need to lint separately.
1. Create a new branch: `git checkout -b my-branch-name`.
1. Make your change, add tests, and make sure the tests still pass.
1. Push to your fork and [submit a pull request][pr].

Guidelines for PRs:

- Fix all problems identified by PR checks.
- Include tests for your changes.
- Keep PRs focused. Submit separate PRs for unrelated changes.
- Write clear commit messages.

Work-in-progress PRs are welcome.
